<h1>ML4Fz</h1>
<p>ML-assisted Windows DLL Fuzzer</p>

---

ML4Fz is a ML-assisted extensible Windows DLL fuzzer **designed to identify <u>potential stack-based buffer overflow vulnerabilities</u> in functions in Export Address Table (EAT) of the target DLL**.
